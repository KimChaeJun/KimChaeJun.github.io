# Technology icons

Bundled SVG assets used by `src/components/TechnologyBadge.tsx`; no external icon requests are made at runtime.

- SVG Logos by Gil Barbara: https://github.com/gilbarbara/logos — CC0-1.0
- Simple Icons by Simple Icons Collaborators: https://github.com/simple-icons/simple-icons — CC0-1.0
- Source data: https://github.com/iconify/icon-sets/tree/master/json (logos.json and simple-icons.json), retrieved 2026-11-04.
- License: https://creativecommons.org/publicdomain/zero/1.0/

The i18next, SQLAlchemy, PowerShell and pytest assets use Simple Icons with brand colors. Other SVG files use SVG Logos. Product names and trademarks belong to their respective owners. The inline symbols for tools without a bundled brand mark are purpose-based drawings, not official logos.
