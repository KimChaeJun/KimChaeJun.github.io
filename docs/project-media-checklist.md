## 추가로 촬영하면 좋은 자료

### LyriKana

- 실제 YouTube Music 연결 상태에서 재생·일시정지·탐색과 가사가 동기화되는 20~40초 영상.
- 확장 프로그램의 표시 설정 화면. 현재 확보한 2장은 실제 Electron 실행 창입니다.

### 119 보이는 ARS

- 공개에 동의한 시연자 또는 비인물 대상을 사용하는 실제 카메라 수신 화면.
- 실제 휴대폰에서의 영상 재생과 세션 생성 → 연결 → 단계 변경 → 종료 과정 녹화.

## 화면 자료를 기다리는 프로젝트

### Tickget

사용자가 기존 자료를 확인할 예정입니다.

- 이미지: 방 목록과 방 생성·입장 화면.
- 이미지: 대기열·캡챠·좌석 선택 단계.
- 이미지: 예매 연습 결과와 개인 기록·경기 분석 화면.
- 영상: 두 사용자 또는 시연용 계정의 좌석 경쟁을 보여주는 30~60초 시연.

## 이미지를 보완하면 좋은 프로젝트

- 흡연·건강지표 분석 대시보드: 웹 앱 전체 개요, 실시간 차트, 기준값 변경 전후. 현재 확보한 이미지는 정적 분석 그래프입니다.
- 건강관리 실습 앱: 수분·운동·수면·식사 입력 화면과 주간 리포트. 현재 확보한 실제 UI는 대시보드 1개입니다.
- SPOANY: 개인정보 없는 예시 티켓으로 OCR 성공·실패와 리뷰 작성까지 이어지는 화면 또는 짧은 영상.

## 저장소 자료 선별 기록 (2026-11-09)

- LyriKana: 기본 브랜치에 이미지·영상 파일과 README 화면 첨부가 없고 릴리스도 없습니다.
- 119 보이는 ARS: 로고, 안내용 그림, CPR 사진은 UI 구성 요소라 실행 캡처에 포함하지 않았습니다.
- Tickget: 좌석도·공연장·배너 이미지와 5초 분량의 인형뽑기 애니메이션은 실행 화면 또는 시연 녹화로 분류하지 않았습니다.
- 분석 이미지 일부는 한글 글꼴이 누락되어 있어, 글자가 정상 표시되는 원본을 우선 선택했습니다.
- SPOANY 매뉴얼 전체, 배포 설정, 계정 정보는 포트폴리오 파일에 포함하지 않았습니다.
